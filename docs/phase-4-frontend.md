# Swing Lab frontend

The application uses Next.js **15.5.29** App Router, React 19, TypeScript,
Tailwind CSS 4, and Zod response validation. It connects to the single-tenant
FastAPI service and generates prompts for manual ChatGPT use.

## Start locally

Use Python 3.12 and Node.js 24. Complete the backend/model setup in the root README.
From the repository root:

```sh
python backend/scripts/init_env.py
cd frontend
npm ci
npm run setup:local
npm run dev -- --hostname 127.0.0.1
```

In another terminal, from the root:

```sh
cd backend
../.venv/bin/python -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log
```

Open <http://127.0.0.1:3000>. The setup helper copies only the backend bearer token
to ignored, mode-0600 `frontend/.env.local`, without printing it or overwriting
existing configuration. Restart Next.js after changing environment settings. If
you rotate the backend token, update the frontend server token as well.

## Capture and review

Upload an MP4, MOV, WebM, AVI, or M4V, or open the camera and record video without
audio. Recordings stop at 30 seconds; the browser limit is 100 MiB. The backend
independently checks duration, decoded content, and resource limits. Camera access
requires HTTPS or localhost and browser permission. Tracks stop on completion,
close, source change, or unmount. Browser/OpenCV codec support varies; MP4/H.264 or
WebM is generally suitable for playback. A browser playback warning does not
prevent backend analysis.

Choose the perspective; posture screening needs a fixed down-the-line view.
Optional start/top/impact markers must all be supplied and ordered inside the
clip. Scrub the player and use its time buttons. Leave all blank for estimation.
For multiple people, enter a normalized point inside your body in frame one.

Analysis shows real transfer progress, followed by elapsed processing time and
a cancel control. Cancel aborts the browser request; server work may continue until
disconnect handling or its hard deadline ends it. Blob URLs and camera tracks are
released on cleanup. The frontend does not automatically retain clips or results.

The video overlay uses decoded timestamps and the same containment transform as
the player, including letterboxing. Interpolated points are amber; missing points
are omitted. An orientation/aspect mismatch hides the overlay with an explanation.
Missing chart samples break the line; unknown metrics show a dash. Wrist speed is
torso lengths per second, not measured clubhead speed.

## Manual coaching

Every successful analysis includes `prompt_payload`. The **AI Coaching Prompt**
card shows it in a labelled read-only textarea, with **Copy to Clipboard** and
**Open ChatGPT** controls. Successful copying is acknowledged only after the
clipboard operation resolves. Unsupported/denied clipboard access selects the
text and explains how to copy manually. The external link opens
`https://chatgpt.com` with `target="_blank"` and `rel="noopener noreferrer"`.
It does not append measurements to the URL, submit data, or send a chat message.

Rule-based observations and drills remain visible alongside the prompt. Save
results exports the full JSON, including the prompt and unsampled kinematic trace.
No AI narrative is fetched or generated by the web server. There is no API-key
context, key input, persistence, or synthesis toggle. The old `/settings` page is
removed. A mount-time migration attempts to remove the retired app's localStorage
entry without reading its value; blocked storage may require clearing site data.

See [the prompt workflow](prompt-workflow.md) for content and migration details.

## Server boundary and deployment

`app/api/v1/analyses/route.ts` streams multipart video/options to the fixed backend
endpoint with server-side bearer auth. It enforces origins, actual streamed bytes,
timeouts and sanitized errors. It forwards only content type and backend auth;
browser cookies, credentials, and retired provider headers are not forwarded.
The route independently rechecks workspace authentication, beyond middleware.

Server-only environment settings (never use `NEXT_PUBLIC_` for credentials):

- `GOLF_BACKEND_URL`: defaults to loopback port 8000. Remote backends require HTTPS.
- `GOLF_API_TOKEN`: matches the backend token; protects analysis access.
- `GOLF_MAX_VIDEO_BYTES`: defaults to 104857600 plus 1 MiB multipart allowance.
- `GOLF_REQUEST_TIMEOUT_MS`: defaults to 300000; the browser timeout is 310 seconds.
- `GOLF_WEB_USERNAME`: Basic auth username; default `coach`.
- `GOLF_WEB_PASSWORD`: at least 16 characters; required for production/non-loopback.
- `GOLF_FRONTEND_ORIGIN`: exact public HTTPS origin, without a trailing slash.
  Set it behind reverse proxies so origin checks match the browser's public URL.

Loopback development bypasses workspace Basic auth. Only in that mode, with no
explicit public origin, matching-scheme/port localhost/127.0.0.1 aliases are
accepted to accommodate Next's local URL normalization. Production checks are exact.
Missing production password configuration returns HTTP 503.

For production, configure HTTPS and private workspace credentials before
`npm run build` / `npm start`. A nonce-based CSP requires dynamic rendering.
HTML/results are no-store. Configure trusted hosts, rate/resource limits, ingress
upload/deadline limits, and credential/body redaction. The route requests a
300-second runtime; hosting plans may impose smaller limits. Choose a Node host
with sufficient upload/time limits or add durable background jobs.

This is a personal workspace, not multi-user identity or storage ownership.
Direct-to-bucket uploads and a licensed pro-video reference library remain separate
integrations. The backend supports configured private Supabase object downloads.

## Verification

```sh
npm test
npm run typecheck
npm run build
```

Tests cover clipboard success/failure, retired-key cleanup, uploads without AI
credentials, response validation, cancellation, proxy header stripping/auth,
origins, byte limits, error redaction, markers, pose lookup, and chart gaps.

For a real Next.js → FastAPI → YOLO smoke test, prepare the backend's ignored
sample/model with `scripts/smoke_pose.py`, start both development servers, and run
`npm run smoke:web`. It validates 24 pose/chart frames and a coaching prompt.
The still sample tests wiring, not golf accuracy. Physical camera/browser codecs
require device-specific testing. Manual ChatGPT submission is left to the user.
